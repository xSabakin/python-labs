# Лабораторна робота №2: Розробка консольних утиліт для задач кібербезпеки

## Варіант 1: Аналізатор журналів веб-сервера (Nginx/Apache Access Log)

### Структура файлів
* labs/lab02/__init__.py
* labs/lab02/main.py — головна точка входу для керування утилітами через командний рядок.
* labs/lab02/task1.py — об'єктно-орієнтована модель користувачів, сесій та журналу аудиту.
* labs/lab02/task2.py — консольна утиліта для розбору та аналізу access.log.
* labs/lab02/data/access.log — вхідні дані для аналізу.

### Встановлення залежностей
З кореня репозиторію в активному віртуальному середовищі виконайте:
`bash
pip install -r requirements.txt

Приклади запуску
 * Запуск демонстрації Завдання 1 (ООП модель):
python -m labs.lab02.main demo

 * Запуск аналізатора логів (Завдання 2):
python -m labs.lab02.main analyze --log-file labs/lab02/data/access.log --output labs/lab02/data/web_analysis_report.json --top 3 --format json

Опис параметрів CLI (Завдання 2)
 * --log-file — шлях до вхідного файлу логу.
 * --output — шлях до файлу звіту.
 * --min-status — мінімальний HTTP статус-код помилки (наприклад, 400).
 * --top — кількість топ IP-адрес із найбільшою кількістю помилок (дефолт: 3).
 * --format — формат вивантаження звіту (json або csv).
